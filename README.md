### ☁️ About The Project

**SkyLit Compass** is a player-made web tool designed to help *Sky: Children of the Light* players track daily shard eruptions, check reward types (Wax or Ascended Shards), and view detailed location maps and spirit memories effortlessly. 

Inspired by the original [Sky Shards](https://sky-shards.pages.dev/) project, it is wrapped in a warm, pastel "cozy-web" scrapbook aesthetic and features real-time countdowns, timezone conversions (Asia/Dhaka & Pacific Time), and multi-day horizon forecasts.

---

### 🎨 Tech Stack

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/)
* **Animations:** [Framer Motion](https://www.framer.com/motion/)
* **Time Management:** [Luxon](https://moment.github.io/luxon/)
